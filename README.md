# MiatOS is a webOS that I made as part of the Stardance Hackclub challenge

---

# Apps

- Miata Notes (Contains notes on the first generation of MX-5s)

- Clock (has an 'analog' clock along with the time in digital form, going hh:mm:ss)

- Game Corner (Showcase of the games I like, and some stats on them at the time of making)

# Features

- Desktop style interface

- Working clock face

- Custom pixel art icons

- Openable apps

- Draggable windows (from the grey header bar)

- ~ALL HAIL THE MIATA~ MX-5 theme desktop


# Code

- HTML

- CSS

- Javascript

  

It was quite a fun project to work on, learn more about JavaScript, and further develop my HTML and CSS skills.

Some assistance was required with the JavaScript.
